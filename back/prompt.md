현재 NoticeFlow라는 서비스를 개발하고있어
이 back 프로젝트에서는 api를 개발하려고해 바이브 코딩을 통해서 만들거야
현재 프로젝트 구조를 읽고 아래에 내가 적은 내용을 API로 만들어줘

공지를 작성하는 api가 필요해
공지 작성은 아래 순서로 진행돼
1. 템플릿 선택(기본 템플릿, 커스텀한 템플릿들)
2. 공지 작성(제목, 카테고리, 내용)
   2-1. 카테고리는 설정에서 관리하도록 할거고 공지 작성시에는 해당 설정에 등록되어있는 카테고리를 사용할거야 추가로 설정에서 카테고리 삭제시 이미 해당 카테고리로 등록되어있는 공지가 있다면 삭제를 못하도록 할거고 숨기기 기능을 둘 예정이야 
   2-2. 내용은 에디터를 사용할거야 그리고 내용에는 변수를 넣을 수 있어 사용 가능한 변수는 {{제목}},{{날짜}},{{기관명}},{{담당자}} 이렇게 4개고 저장시 자동으로 치환 될거야
3. 사용자들에게 발송

지금 필요한 API는 1번과 2번이야 3번 사용자 발송은 나중에 기획이 좀더 완성되면 할 예정이야
템플릿 선택은 우선 기본 템플릿만 할 예정이야
기본 템플릿은 
- 템플릿 이름: 기본 템플릿
- 설명: 빈 템플릿
- 내용: 에디터를 사용할거고 기본 템플릿 내용은 비워둘거야
